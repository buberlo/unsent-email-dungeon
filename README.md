# Unsent Email Dungeon

> Your draft folder is a dungeon where unfinished sentences become monsters.

A solo roguelike where every email draft is a cursed spell that mutates the longer it sits unsent. You explore rooms made of inboxes, delete weak drafts, finish strong ones, and send risky messages that may trigger backlash. The final boss is a giant apology email you never sent.

## Features
- Generate monsters from draft length, tone, and unopened status
- Fight with actions like finish, delete, or send early
- Trigger inbox backlash if you send an undercooked draft
- Face a final boss built from your oldest abandoned apology

## Stack
- Phaser
- TypeScript
- Howler.js

## Getting started
```
npm install && npm run dev
```
